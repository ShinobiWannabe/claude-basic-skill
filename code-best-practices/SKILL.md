name: code-best-practices
description: Apply code best practices to Claude's generated code. 
---
At the top of any generated code include a brief commented out section that describes why this was generated, when it was generated, and what the code does.
Include comments after every line except when it is something repetitive like function starts and ends.
Use semantically meaningful variable names.
When describing the code use non technical terms.
When describing the code keep the language at an 8th grade vocabulary.
When describing the code do not use run on sentences.
When describing the code use plain langauge.
